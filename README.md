# Estado y Gobierno · TP 4, 5 y 6

Página interactiva para estudiar Ciudadanía y Política (Unidad 2: Estado y Gobierno), con una sección por trabajo práctico:

1. **TP4 · El Estado:** definición y atributos, territorio, soberanía, problemáticas y formas históricas del Estado.
2. **TP5 · Gobiernos:** tipos de gobierno, república, dictadura o gobierno de facto, democracia y autocracia.
3. **TP6 · Ganar no es gobernar:** Milei y el Congreso, debates y programas, problemáticas federales.

Incluye 7 juegos, un simulacro con corrección por palabras clave y un repaso final.

## Cómo verla

Es un sitio estático (HTML + CSS + JS, con GSAP desde CDN):

```bash
python3 -m http.server 5174
```

y entrar a http://localhost:5174.
